Smart – Face Recognition System

About the Project
VisionX is a Python-based real-time face recognition system built using OpenCV. It uses computer vision to detect and recognize faces through a webcam and can provide voice alerts.

 Features
- Real-time webcam access
- Face detection using Haar Cascade
- Face recognition using LBPH
- Voice alerts using pyttsx3
- Capture and save face images
- Train a face recognition model

 Technologies Used
- Python
- OpenCV
- NumPy
- pyttsx3

 Project Files
 main.py– Runs the real-time face recognition system.
capture_photo.py – Captures and saves face images.
train_faces.py– Trains the face recognition model.

Installation

Install the required libraries:

bash
pip install opencv-contrib-python numpy pyttsx3


How to Run

Step 1: Capture a face image.

bash
python capture_photo.py


Step 2: Train the face recognition model.
bash
python train_faces.py


Step 3: Run the main program.
bash
python main.py


Requirements
Python 3.12 or compatible version
Webcam
Windows, Linux, or macOS with a compatible camera
